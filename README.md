Repositorio con los entregables para los labs del curso MDS7202 Laboratorio de Programación Científica para Ciencia de Datos

# Estructura del repositorio

## main

La rama main contiene todos los entregables juntos, incluyendo:

- Entregables_Lab1 a Entregables_Lab11
- Entregables_Entrega_Parcial1
- Entregables_Entrega_Parcial2
- README.md

Esta rama sirve como visión global de todo el material evaluado del curso.

## lab{n}

Cada rama labn contiene solo la carpeta del laboratorio correspondiente, por ejemplo:
- lab1 → Entregables_Lab1
- lab2 → Entregables_Lab2
  
...
- lab11 → Entregables_Lab11

Estas ramas están diseñadas para mostrar únicamente el desarrollo de cada laboratorio de forma aislada.

## parcial{n}

Similarmente a los laboratorios, las ramas parcialn contienen únicamente:

- parcial1 → Entregables_Entrega_Parcial1
- parcial2 → Entregables_Entrega_Parcial2

Útiles para mostrar el desarrollo de las entregas parciales del proyecto de forma separada
